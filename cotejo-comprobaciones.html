Cotejo de comprobaciones

Carátula + soportes → relaciones → paquete de entrega

1. Datos de la comprobación

No se envían documentos al servidor. Los archivos se procesan temporalmente en tu navegador.

2. Importar carátula

Acepta CSV y Excel (.xlsx/.xls). Selecciona la fila que contiene los encabezados si es necesario. También puedes capturar renglones manualmente.

3. Recibir soportes

También acepta ZIP con soportes. Los XML y PDF con el mismo nombre base se vinculan como pareja; la asociación al renglón sigue siendo una propuesta.

4. Excepciones de comprobación

Alertas orientativas: una fotografía o ticket no siempre requiere XML; confirma las reglas de cada producción. Los importes de XML se comparan contra la carátula cuando hay un único XML por renglón.

5. Exportar entrega

0 renglones · 0 soportes

Solo se incluyen soportes asociados y confirmados. Los originales no se modifican.

El ZIP incluye soportes renombrados, carátula de cotejo CSV y manifiesto JSON. La carátula Excel original se conserva dentro del ZIP si fue importada, pero sus celdas no se modifican.
